# VoltCart — Electrical Retail Website

A beginner-friendly React + Vite storefront for an electrical supplies business.

## Run locally

1. Install [Node.js](https://nodejs.org/) (version 18 or newer).
2. Clone this repository.
3. In the project folder, run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite (normally `http://localhost:5173`).

## Included in this first version

- Responsive storefront homepage
- Product categories, search, filtering, and sorting
- Product cards with add-to-cart actions
- Cart drawer with quantity controls and subtotal
- Newsletter signup interaction
- Responsive mobile navigation
- About/contact/footer entry points ready for expansion
